# Sainos
An Android application dedicated to making work-life in one of the UK's biggest retailer easier. With multiple functions for Services Assistants to perform their role quickly and efficiently.
# Features
-> Dynamic Closing Script (WIP)
-> Cold Chain Timing (WIP)
-> Speed-Dialing (WIP)
-> Product Comparisons (WIP)
-> Fishing Temporary Logs (WIP)
-> Shopping List (WIP)
-> Nectar Card and Colleague Card Storage (WIP)
